\# AI Warehouse Search Agents



This repository contains implementations of multiple search-based agents

for a competitive multi-agent warehouse environment.



The project was developed as part of \*\*Introduction to Artificial Intelligence – Homework 2\*\*.



\## Implemented Agents



\- Improved Greedy Agent with custom heuristic

\- Minimax Agent (adversarial search)

\- Alpha-Beta Pruning Agent

\- Expectimax Agent (stochastic opponent model)



\## Heuristic Design



The heuristic prioritizes:

\- Maximizing accumulated credit

\- Efficient package delivery

\- Battery-aware movement toward packages or charging stations



The heuristic dynamically adapts based on whether the robot is:

\- Carrying a package

\- Searching for a package

\- Low on battery



\## Environment



Agents operate in a grid-based warehouse environment with:

\- Two competing robots

\- Packages with destinations

\- Charging stations

\- Turn-based actions
